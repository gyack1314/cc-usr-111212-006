# 多表目录及候选

示例read_set映射中用snapshot ID表达预期，实际比较需校验该ID规范元数据摘要及全部资产摘要。release完整表映射是不可变记录，当前指针在同一SQLite事务切换。write_set列出替换表，同表不可重复；未写表沿当前映射保留，所以互不影响候选可重基。

固定外键仅在其from或to表被写时触发，两个端点都加入验证read_set。外键要求非null来源值在目标主键集合中，目标主键唯一；null来源按SQL外键跳过。表行数从JSONL实际计数，禁止空行，不支持任意SQL约束。候选验证针对write_set合并到当时当前映射的版本，read_set缺任何约束依赖直接拒绝；提交重验预期版本。

新表首次建造read_set填{"absent":true}。操作规范摘要含基准、完整读写集和内容身份。同操作成功后重试返回已记录release，即使current后来又变。读句柄只引用release ID，本次不回收快照。可信数据路径从资产清单获取，数据源不决定输出路径。
